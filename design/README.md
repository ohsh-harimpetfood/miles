# DESIGN

DESIGN은 MILES와 구현 시스템에서 반복적으로 사용하는 visual language, interaction principle, packaging, identity, reference를 관리하는 영역입니다. 장식 자체보다 정보와 실행을 더 명확하게 만드는 설계를 다룹니다.

## Purpose

시각적·상호작용적 일관성을 유지하고, 정보 밀도와 사용 흐름을 개선하는 재사용 가능한 design guidance를 축적합니다.

## Belongs Here

- UI principles
- visual language
- information-density principles
- interaction patterns
- design references
- packaging / presentation rules
- identity system

## Does Not Belong Here

- 특정 시스템의 전체 구현 설명 → `FORGE`
- 단순 이미지 저장을 위한 dump
- 근거 없는 aesthetic preference

## Evidence / Entry Expectations

가능한 경우 어떤 정보 문제나 사용성 문제를 해결하는지, 실제 적용에서 어떤 효과를 기대하거나 관찰했는지 설명합니다. 공개 자료를 사용할 때는 출처와 publication safety를 고려합니다.

## Relationship to Other Areas

DESIGN은 `FORGE`와 `WORKBENCH`의 인터페이스와 표현 방식을 지원하며, 반복 검증된 design principle은 MILES 전반의 공통 언어로 재사용될 수 있습니다.
