# WORKBENCH

WORKBENCH는 아직 확정되지 않은 실험, PoC, prototype, 기술 탐색을 기록하는 영역입니다. 검증되지 않은 것을 production-ready인 것처럼 표현하지 않습니다.

## Purpose

아이디어와 기술적 가능성을 빠르게 시험하고, 실패와 학습을 포함한 검증 과정을 남깁니다.

## Belongs Here

- prototypes
- proof of concepts
- spikes
- feasibility tests
- alternative architecture experiments
- AI experiments
- exploratory automation

## Does Not Belong Here

- 안정적으로 운영되는 구현 → `FORGE`
- 검증을 마친 재사용 방법론 → `METHODS`

## Evidence / Entry Expectations

실험의 질문, 가정, 조건, 결과와 한계를 가능한 한 명확히 남깁니다. 실패한 실험도 재사용 가능한 학습이 있다면 기록할 수 있습니다.

## Relationship to Other Areas

WORKBENCH는 `GROUNDTRUTH`와 `SIGNALS`에서 나온 문제와 가설을 시험할 수 있습니다. 충분히 검증되고 실제 운영으로 이동한 구현은 `FORGE`로 승격할 수 있고, 반복 적용 가능한 방식으로 정제된 경우 `METHODS`로 발전할 수 있습니다.
