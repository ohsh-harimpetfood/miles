01 / WHO I AM

현실의 운영 문제를 시스템으로 바꾸는 사람.

2009년부터 식품 제조업에서 생산관리와 품질관리를 맡으며 공정·설비·재고까지 실제 제조 운영을 다뤄왔다. 전처리, 살균·멸균, CIP, 탱크, 자동화 공정과 생산라인의 개선·증설·구축 경험을 거쳐, 이후 MES / WMS, SAP ERP / PI, 데이터와 자동화, AI-assisted implementation까지 문제 해결 범위를 확장했다.

지금은 제조 운영을 관리해온 경험과 공정·설비 engineering capability를 바탕으로, 문제에 따라 물리적인 공정과 설비를 바꾸거나 디지털 시스템과 데이터 구조까지 확장해 실행 가능한 해결책을 만든다.

운영을 관리하고, 공정·설비를 개선·구축하고, 필요하면 디지털 시스템까지 직접 만든다.

WHO FIRST

프로젝트를 보여주기 전에, 어떤 현실에서 출발했고 어떤 방식으로 문제를 다루는 사람인지 먼저 설명한다.

I DID NOT START AS A DEVELOPER

나는 개발자로 출발하지 않았다.

2009년부터 식품 제조업에서 일해왔다. 생산관리와 품질관리 업무를 통해 라인, 설비, 원료, 공정조건, 생산실적, 재고, 품질 이상과 같은 물리적인 운영 문제를 먼저 경험했다.

소프트웨어를 먼저 배우고 현장으로 간 것이 아니라, 제조 운영을 오래 다루다 보니 기존 시스템만으로 해결되지 않는 문제들이 계속 보이기 시작했다.

  • 왜 현장에서는 알고 있는 사실이 시스템에서는 보이지 않는가?
  • 왜 데이터가 있는데 사람이 다시 정리해야 하는가?
  • 왜 시스템을 구축했는데 운영 방식은 바뀌지 않는가?
  • 왜 반복해서 발생하는 문제를 계속 사람이 감당해야 하는가?

이 질문들이 내가 시스템을 만드는 쪽으로 이동하게 된 출발점이었다.

THREE CAPABILITIES

제조 운영을 관리하고, 물리적인 공정·설비를 engineering하고, 필요하면 디지털 시스템까지 직접 구현한다.

01

Manager

생산, 품질, 사람, 공정, 설비, 실적, 원가, 재고와 실행 흐름을 하나의 제조 운영체계로 관리해왔다. 물리적 운영의 제약을 시스템 밖의 변수로 취급하지 않는다.

02

Engineer

자동화 제조공정의 전처리 설비와 생산라인을 실제로 개선·증설·구축해왔다. 살균·멸균, CIP, 탱크, 유당분해 공정, 신규·증설 라인처럼 생산능력과 품질·위생·운영 제약을 함께 고려해 물리적인 제조 시스템을 바꿔왔다.

03

Builder

현장 운영이나 공정·설비 개선만으로 해결되지 않는 문제는 MES, WMS, ERP / SAP integration, 데이터, 자동화와 Web Application까지 확장해 직접 실행 가능한 시스템으로 구현한다. 필요하면 SQL, Python, Apps Script, Streamlit, Database와 AI-assisted implementation을 사용한다.

목적은 개발자가 되는 것이 아니다. 제조 관리와 공정·설비 engineering 판단을 실제 실행 상태까지 연결하는 것이다.

AI AND IMPLEMENTATION

AI는 내 판단을 대신하는 것이 아니라, 구현 가능한 범위를 넓힌다.

문제 정의, 업무 규칙, 운영 제약, 아키텍처 판단과 최종 검증은 사람이 통제한다.

구현, 대안 탐색, 반복 코딩, 문서화와 분석 보조에는 AI를 적극적으로 사용한다.

Implementation is delegated. Intent is retained.

Autonomous AI operation 또는 formal methodology status를 주장하지 않는다.

CORE IDEA

현실의 운영 문제를 구조화하고, 필요한 경우 공정·설비·시스템까지 실제로 바꾼다.

관리에서 engineering, implementation까지 필요한 층위를 연결해 문제를 실행 가능한 상태로 만든다.
