02 / WHAT

어떤 문제를 다뤄왔는가

도메인은 기술 목록이 아니라 실제 운영 문제를 다뤄온 범위다.

Manufacturing Operations

생산 현장의 흐름, 품질, 재고와 작업 실행을 시스템 관점으로 다룬다.

production · yield · inventory · shop-floor operation

Execution Systems

현장 실행을 지속 가능한 operational application으로 연결한다.

MES · WMS · operational applications

Enterprise Process

현장과 기업 시스템 사이의 프로세스, 기준정보, 통합 구조를 설계한다.

ERP · SAP PI · master data · process design

Data & Intelligence

운영 데이터를 판단 가능한 signal과 decision support로 바꾼다.

ETL · analytics · dashboards · decision support

Automation

반복 업무와 정보 전달 흐름을 자동화 가능한 execution path로 만든다.

RPA · automated reporting · workflow

AI-native Work

AI를 도메인 지식과 Git-backed execution discipline 안에서 활용한다.

Docs as Code · Feature as Code · Git as Action
