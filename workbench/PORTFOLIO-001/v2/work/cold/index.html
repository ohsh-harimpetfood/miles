01

보기 → 비교하기

데이터는 있었지만 비교하기 어려웠습니다

TURN TEMPERATURE RECORDS INTO A COMPARABLE VIEW.

개별 온도값과 최저온도만으로는 여러 냉동 컨테이너(CT)의 상태를 같은 기준으로 비교하기 어려웠습니다. 센서값을 더 많이 보여주는 대신, 시간이 지나도 서로 비교할 수 있는 분석 방식을 만드는 데 초점을 맞췄습니다.

Google Sheets / CSV 데이터를 Python과 Colab으로 분석하기 시작했고, 비교 기준과 시각화를 만든 뒤 Streamlit 분석 화면으로 확장했습니다.

GOOGLE SHEETS / CSV→PYTHON / COLAB→비교 / 차트→STREAMLIT
온도→시간에 따른 안정성→CT 간 비교→운영 패턴

한 번의 낮은 온도는 쉽게 보였습니다. 반복되는 운영 패턴은 그렇지 않았습니다.

02

분석 → 행동

분석은 실제 행동으로 이어져야 했습니다

THE RESULT HAD TO REACH THE PEOPLE USING IT.

분석 결과는 화면에서 끝나지 않았습니다. 현재 상태와 최근 추세를 정비·제상·회복 이력과 함께 확인하고, AI가 이 정보를 바탕으로 점검할 내용과 권장 조치를 정리하도록 했습니다. 그 결과를 운영 보고서로 반복 배포하고, 최종 확인과 조치는 사람이 담당했습니다.

온도 데이터→정해진 기준으로 분석→현재 상태 + 추세 + 정비 이력→AI가 맥락과 권장 조치 정리→운영 보고서→사람이 확인 / 조치

보고 방식의 확장

AI와 사람의 역할

기준 분석→정비 이력→AI 맥락 정리→사람의 판단과 조치
AI가 스스로 진단·정비·수리한다고 주장하지 않습니다. AI 진단 정확도도 아직 검증된 성과로 제시하지 않습니다.
