WMS-001 / 실제 화면

SEE THESYSTEM WORK.

이 페이지는 실제 운영 시스템에서 공개 가능한 화면을 중심으로 구성합니다. 창고 맵, QR·랙카드, 이동 이력, 사용자 권한, 여러 형태의 보관 공간, 재고 실사까지 실제 작업 흐름을 따라갑니다.

01 / 맵 · 창고 전체 보기

SEE THE WAREHOUSE AS ONE SYSTEM.

창고 위치와 재고 점유 상태를 하나의 맵에서 확인합니다. 위치를 찾고, 해당 위치의 재고 상태로 바로 들어가는 운영 화면입니다.

창고 위치→맵→재고 상태

02 / 현장 연결 · 랙카드와 QR

CONNECT THE SCREEN TO THE RACK.

랙카드와 QR은 실제 창고 위치를 시스템의 위치 정보와 연결합니다. 작업자가 현장에서 위치를 식별하고 필요한 작업으로 들어가는 접점입니다.

실제 랙→QR / 랙카드→시스템 위치

03 / 이동 이력 · 무엇이 움직였는가

MOVEMENT BECOMES A TRACE.

입고·출고·이동이 기록으로 남습니다. 품목이 어디에서 어디로 움직였는지 운영 이력에서 확인할 수 있습니다.

입고→이동→출고→이력

04 / 권한 · 사람마다 다른 기능

CONTROL WHO CAN DO WHAT.

여러 사용자가 같은 시스템을 쓰기 때문에 역할별로 사용할 수 있는 기능을 구분합니다. 화면 접근과 작업 권한을 운영 구조 안에 포함했습니다.

사용자→역할→사용 가능한 기능

05 / 보관 구조 · 랙만 있는 창고가 아닙니다

MODEL DIFFERENT STORAGE TYPES.

실제 창고에는 랙뿐 아니라 냉동·비랙 보관 공간도 있습니다. 시스템은 이런 서로 다른 보관 구조를 하나의 위치 모델 안에서 다룰 수 있도록 확장됐습니다.

랙+비랙+냉동 보관→하나의 위치 구조

06 / 재고 실사 · 시스템과 현장 맞추기

CHECK THE SYSTEM AGAINST THE FLOOR.

재고 실사는 시스템에 기록된 수량과 실제 현장 상태를 다시 맞추는 과정입니다. 출력물은 현장 확인을 위한 운영 도구로 사용됩니다.

시스템 재고↔현장 확인→재고 실사

설명용 파생 이미지

TWO VISUALS EXPLAIN THE SYSTEM. THEY ARE NOT RAW EVIDENCE.

두 이미지는 공개 포트폴리오에서 구조를 이해하기 쉽게 보여주기 위해 만든 파생 이미지입니다. 실제 시스템의 원본 화면과 같은 등급의 검증 자료로 취급하지 않습니다.

6 실제 검증 화면+2 설명용 파생 이미지

실제 화면은 시스템이 존재하고 사용되었음을 보여주고, 파생 이미지는 특정 설계 개념을 이해하기 쉽게 설명합니다.

다음 단계

SEE THE WORK. THEN VERIFY IT.

여기서는 실제 화면을 보여줬습니다. Evidence 페이지에서는 각 자료가 무엇을 입증하고 무엇은 아직 입증하지 않는지 확인할 수 있습니다.
