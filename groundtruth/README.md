# GROUNDTRUTH

Groundtruth contains observed manufacturing reality.

Examples:

- operational problems
- factory constraints
- logistics constraints
- warehouse reality
- process limitations
- field observations
- real-world evidence

Groundtruth is where MILES starts.

Before systems, there is reality.
